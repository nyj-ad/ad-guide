# 03. 현행 기준 검증 기록

- 확인일: 2026-11-11
- 데이터: `data/regulations.json` (규칙 26건)
- 원칙: 검증 상태가 '미확인'인 규칙은 판정에 쓰지 않고 "근거 미확인으로 판정 불가"로만 표시

## 1. 적용 관계

1. 옥외광고물법·시행령: 허가·신고 대상, 표시방법의 큰 틀
2. 경기도 조례: 광고물 종류별 표시방법의 세부 기준(일반 기준)
3. 남양주시 특정구역 고시(경기도 고시 제2025-3호): 지정 구역 안에서는 이 고시가 일반 기준보다 우선하고 더 엄격함
4. 정비시범구역 고시: 해당 구역의 별도 표시방법

## 2. 출처별 검증 상태

| 출처 | 식별 | 검증 방법 | 상태 |
|---|---|---|---|
| 옥외광고물법 시행령 | 대통령령 제36054호, 2026. 1. 27. 타법개정 | 국가법령정보센터 화면에서 공포번호·시행일 확인 | 원문 확인 |
| 경기도 옥외광고물 조례 | 법제처 찾기쉬운 생활법령정보 「옥외광고물(경기도)」, 2026. 10. 15. 기준 | 법제처 해설 본문에서 수치와 조문 표기 확인 | **해설로 확인(조례 원문 대조 전)** |
| 남양주시 특정구역 지정 및 표시제한·완화 고시 | 경기도 고시 제2025-3호, 2025. 1. 8. | 담당자 보유 고시문 원본(hwp) 전문 열람. 구역 목록 표·위치도 그림은 기계 판독 못 함 | 원문 확인 |
| 남양주시 옥외광고물 조례 | 조례 제2488호, 2025. 12. 29. 시행 | 수수료(제25조, 별표 3·4)만 확인 | 표시방법 조항 **미확인** |
| 정비시범구역 고시 | 미확인 | 원본 파일 보유, 내용 미분석 | **미확인** |

## 3. 규칙별 상태 요약

| 구분 | 건수 | 판정 사용 |
|---|---|---|
| 원문 확인(특정구역 고시) | 13 | 사용 |
| 법제처 해설로 확인(경기도 조례) | 11 | 사용. 화면에 "조례 원문 대조 전"이라고 표시 |
| 미확인(정비시범구역, 남양주시 조례 표시방법) | 2 | 사용하지 않음 |

규칙별 조문·수치·예외·확인일은 `data/regulations.json`에 있습니다.

## 4. 화면에 표시하는 판정 4가지

| 표시 | 조건 |
|---|---|
| 확인된 기준에 부합 | 판정한 항목이 모두 범위 안 |
| 확인된 기준상 제한 또는 위반 가능성 | 범위를 벗어난 항목이 하나 이상 |
| 추가 조건 확인 필요 | 창문 없는 벽면(심의 대상), 구역을 모르는 경우 |
| 근거 미확인으로 판정 불가 | 정비시범구역 등 기준을 확인하지 못한 경우 |

모든 결과 화면에 "허가증이나 적합 확인서가 아니며, 최종 판단은 담당 부서가 한다"는 문구를 함께 표시합니다.

## 5. 담당자 확인이 필요한 사항

1. 경기도 조례 원문(제8조 등)과 법제처 해설 수치의 대조. 이 작업 환경에서 국가법령정보센터 자치법규 화면을 열지 못했습니다.
2. 특정구역 고시의 구역 목록·위치도에서 진건읍 해당 구간 확인
3. 정비시범구역 고시 내용 입력
4. 남양주시 조례의 표시방법 관련 조항 유무
5. 경기도 조례 개정 시 `data/regulations.json`의 수치·확인일 갱신
