# 02. PDF 그림 분석 (2.pdf)

- 자료: 2.pdf — 옥외광고 실무 커뮤니티에 실린 현장 사진 도해 자료 「가로형광고물의 표시방법」, 2005. 5. 27., 3쪽(담당자가 열람 후 인쇄본으로 제공)
- 분석일: 2026-11-11
- 방법: 각 쪽을 그림으로 변환해 AI(Claude)가 사진과 글자를 읽음. 글자 정보가 없는 그림 PDF라 문자 추출은 쓰지 못함
- 구조화 결과: `data/historical-visual-examples.json` (7건)

> **이 자료는 과거 참고자료입니다.** 2005년 게시글의 수치는 현행 기준이 아니며, 사이트의 판정에 쓰지 않습니다. 참고한 것은 "사진 위에 선과 색으로 기준을 보여 주는 방식"뿐입니다.

## 2. 표현 방식에서 배운 점

| 원본의 방식 | 새 서비스에 적용한 방식 |
|---|---|
| 빨간색 = 한도, 초록색 = 기준 길이 | 초록 점무늬·점선 = 확인된 기준 범위, 파란색 = 내 간판, 빨간 빗금 = 벗어난 부분 |
| 실제 건물 사진 위에 선을 그림 | 직접 그린 건물 그림(SVG) 위에 표시. 사진은 쓰지 않음 |
| 색으로만 구분 | 색 + 무늬(점·빗금) + 글자 설명 + 범례를 함께 제공 |
| 한 장의 고정된 예시 | 입력값에 따라 그림과 결과가 바뀜 |
| 앞에서 본 모습 한 가지 | 앞에서 본 모습과 옆에서 본 모습(돌출폭) 두 가지 |

## 3. 저작권·개인정보 처리

- 원본 사진에는 행인, 상호, 전화번호가 찍혀 있고 제3자의 저작물입니다.
- 사진과 PDF는 저장소와 사이트에 싣지 않았습니다. 자동 점검으로 확인합니다(`tests/site.test.js`).
- 저장한 것은 글자 내용과 위치 설명뿐입니다.
