## 3. 문제점

| 번호 | 문제 | 근거 | 우선순위 |
|---|---|---|---|
| 1 | 간판을 **어디에, 얼마나 크게** 달 수 있는지 안내가 없음 | #standards 화면 본문 739자 중 표시방법 수치 0건, 그림 0개, 입력란 0개 | 높음 |
| 2 | 글 중심이라 건물과 간판의 관계를 떠올리기 어려움 | 표시 기준 화면에 그림 없음 | 높음 |
| 3 | 남양주시 특정구역(진건지구 등)의 더 엄격한 기준이 반영되지 않음 | 특정구역 고시 링크만 있음 | 높음 |
| 4 | 기준 수치가 코드 안에 섞여 있어 고칠 때 코드를 직접 수정해야 함 | 수수료·대상 기준이 index.html 상수 | 중간 |
| 5 | 자동 점검이 없어 고친 뒤 다른 기능이 깨졌는지 확인하기 어려움 | tests 폴더 없음 | 중간 |
| 6 | 근거 조문의 확인일·검증 상태가 규정별로 표시되지 않음 | 화면 하단에 기준월만 표시 | 중간 |
