# AI 활용 증빙

- 사용 도구: Anthropic Claude (대화형 작업 환경에서 파일 분석·코드 작성·자동 점검 실행)
- 기간: 2026-11-03 ~ 2026-11-11
- 사람: 담당 공무원 1명(요구사항 제시, 자료 제공, 화면 확인, 방향 결정)

## 0. AI 기여 한눈에 보기

| 입력 | AI가 한 작업 | 사람의 검토 | 최종 반영 |
|---|---|---|---|
| 과거 그림 자료(2.pdf) | 사진 위 글자·치수선·색의 의미를 7건으로 구조화, 불확실한 부분에 신뢰도 표시 | 자료 제공, 과거 수치를 현행 기준으로 쓰지 않도록 지시 | 색·무늬로 기준을 보여 주는 그림 표현에만 반영 |
| 특정구역 고시문, 법제처 해설 | 규칙 26건 초안(조문·출처·확인일) 작성 | 고시문 원본 제공. 조례 원문 대조는 진행 예정 | 확인된 24건만 판정에 사용, 2건은 판정 불가 |
| 업무 요구사항(대화) | 화면·그림·판정 코드·자동 점검 63건 작성 | 휴대폰 화면 확인, 디자인·문구 수정 요청 | 작업본(배포 승인 대기) |

개발에 쓴 모델: Anthropic Claude(Claude Opus 5.5, Claude Fable 5.2). 서비스 실행 시 쓰는 모델: 없음.

## 1. 문제를 발견한 과정

- 기존 표시 기준 화면을 AI가 읽고 본문 739자 안에 표시방법 수치가 없고 "세부 수치는 확인이 필요합니다"로 끝난다는 점을 확인했습니다(`docs/01-current-site-audit.md`).

## 2. PDF 그림 분석

| 입력 | AI가 한 일 | 결과 |
|---|---|---|
| 글자 정보가 없는 그림 PDF 3쪽 | 쪽을 그림으로 바꿔 사진 위 글자·선·색을 읽음 | 7건 구조화(`data/historical-visual-examples.json`) |
| 쪽 경계에서 잘린 "30Cm이내" | 두 쪽의 조각을 맞춰 읽고 신뢰도 '중간'으로 표시 | 단정하지 않고 표시 |
| 사진 범위 밖의 건물 층수 | 추정하지 않음 | "단정하지 않음"으로 기록 |

## 3. 기준 데이터 검증

- 특정구역 고시문 전문(hwp)을 읽어 규칙 13건 정리(조·항·호·목까지 기록)
- 법제처 생활법령 해설에서 경기도 조례 기준 11건 정리, "조례 원문 대조 전"으로 표시
- 확인하지 못한 2건은 판정식 없이 '미확인'으로 등록
- 기록: `docs/03-regulation-verification-log.md`

## 6. 실패한 시도와 개선

| 시도 | 결과 | 대응 |
|---|---|---|
| 네이버 카페 글을 AI가 직접 열기 | 접근 차단 | 담당자가 인쇄한 PDF를 받아 분석 |
| 국가법령정보센터 자치법규 화면에서 경기도 조례 원문 확인 | 이 작업 환경에서 열리지 않음 | 법제처 해설로 확인하고 상태를 낮춰 표시 |
| 새 화면 연결 | 스크립트 연결이 빠져 화면이 비어 보임 | 화면 점검에서 발견해 수정 |
| 결과 상자 색 | '제한' 결과가 보라색으로 표시됨 | 빨간 계열로 수정 |

## 7. AI 사용의 한계

- AI가 읽은 수치는 원문과 대조해야 합니다. 그래서 규칙마다 검증 상태를 두었습니다.
- 구역 목록 표와 위치도 그림은 기계로 읽지 못했습니다.
- 실제 민원인의 이해도는 AI가 측정할 수 없습니다.

## 8. 재사용할 수 있는 업무 절차

1. 과거 안내 자료(사진·그림)를 AI로 읽어 "표현 방식"과 "수치"를 분리
2. 현행 법령·조례·고시를 출처·확인일과 함께 데이터로 정리
3. 과거 수치와 현행 기준을 대조해 차이를 기록
4. 확인된 기준만 판정에 쓰는 화면 제작
5. 자동 점검으로 판정 결과와 기존 기능 확인
6. 담당자 검토 후 배포

## 9. 프롬프트 예시

- "모바일에서 화면구성이 안 예뻐. 글자 자간 조정해줘. 애매하게 줄 넘기지 않게."
- "제공된 PDF는 역사적 참고자료이지 현행 법적 기준이 아님을 명확하게 할 것. 법령을 확인할 수 없으면 추측하거나 허구의 수치를 만들지 말 것."
