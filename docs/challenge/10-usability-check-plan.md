# 예비 사용성 확인 계획과 기록지

> **현재 상태: 미실시.** 아래 결과 칸은 비어 있습니다. 실시하지 못하면 이 문서를 "측정 계획"으로 제출하고, 수치를 채워 넣지 않습니다.

## 1. 방법

| 항목 | 내용 |
|---|---|
| 대상 | 옥외광고물 업무를 하지 않는 사람 3~5명. 동료·지인이면 "편의 표본"이라고 적습니다 |
| 도구 | 휴대폰. 개선 전 화면(커밋 97f23b6)과 개선 후 화면 |
| 시간 | 1명당 10분 안팎 |
| 순서 | 학습효과를 줄이기 위해 절반은 개선 전 → 후, 절반은 후 → 전. 두 화면에 서로 다른 문제를 줍니다 |
| 측정 | 과제 완료 여부, 걸린 시간(초), 잘못 이해한 내용 |

## 2. 과제

| 문제 | 내용 | 정답(기준 데이터 기준) |
|---|---|---|
| A | 특정구역 밖 3층 건물 1층, 창문 사이 벽면 높이 100cm. 가로형 간판 세로를 최대 몇 cm까지 달 수 있습니까? | 100cm 이내 |
| B | 특정구역 밖에서 가로형 간판은 벽에서 최대 몇 cm까지 튀어나올 수 있습니까? | 30cm 이내 |

- 제한 시간 3분. 넘으면 "미완료"로 적습니다.
- 진행자는 힌트를 주지 않습니다.

## 5. 제시할 때 지킬 점

- 제목은 "예비 사용성 확인"으로 하고 참가자 수와 표본 성격을 함께 적습니다.
- 전체 시민 효과로 일반화하지 않습니다.
- 민원 감소·시간 절감은 운영 후 측정 항목으로 따로 적습니다.

## 6. 개선 전 화면 띄우는 방법

```
git worktree add ../ad-guide-before 97f23b6
cd ../ad-guide-before && python3 -m http.server 8766
```
같은 와이파이의 휴대폰에서 `http://(PC 주소):8766/` 으로 엽니다.
