# 구동안내서 (초안)

> 대회 지정 양식(양식2-1)을 받지 못해 일반 항목으로 작성했습니다. 지정 양식의 항목 순서에 맞춰 옮겨 적어야 합니다. 분량은 A4 3~5쪽 기준입니다.

## 1. 과제 개요

| 항목 | 내용 |
|---|---|
| 과제명 | 간판 기준을 내 건물 그림으로 — AI 활용 시민 맞춤형 사전안내 |
| 기관·부서 | 남양주시 진건·퇴계원행정복지센터 도시건축과 건축팀 |
| 형태 | 웹페이지(설치 없음, 휴대폰·PC 브라우저) |
| 개발에 쓴 AI | Anthropic Claude |
| 실행 중 쓰는 AI 모델 | 없음(검증한 규칙 데이터로 대조) |
| 외부 연계 | 없음. 등록업체 목록만 시 누리집 공개 자료를 하루 한 번 받아 둠 |
| 개인정보 | 수집 없음 |

## 2. 실행 방법

### 가. 저장소에서 실행 (심사용, 인터넷 없이 가능)

1. 저장소를 내려받습니다.
2. 저장소 폴더에서 아래 명령을 실행합니다(Python 3만 있으면 됩니다).
   ```
   python3 -m http.server 8765
   ```
3. 브라우저에서 `http://localhost:8765/` 를 엽니다.

※ index.html을 더블클릭해 열면 기준 자료를 읽지 못해 그림 안내가 "불러오지 못했습니다"로 나옵니다. 반드시 위 방법으로 여십시오.
※ 글꼴(Noto Sans KR)은 인터넷이 있을 때만 내려받습니다. 없으면 기기 기본 글꼴로 보이며 기능은 같습니다.

### 나. 공개 주소로 접속

- https://nyj-ad.github.io/ad-guide/ (배포 승인 후 제출본과 같은 내용으로 반영)

## 3. 핵심 시나리오 (그대로 따라 하면 같은 결과가 나옵니다)

첫 화면에서 **내 간판 설치기준 알아보기**를 누릅니다.

| 번호 | 조작 | 기대 결과 |
|---|---|---|
| 1 | ① 벽면 이용 간판 ② 특정구역 밖 ③ '기준 범위 안에 든 예' | "확인된 기준에 부합" |
| 2 | '범위를 벗어난 예' 누름 | "확인된 기준상 제한 또는 위반 가능성", 빨간 항목 3건(가로·세로·돌출) |
| 3 | '지금 값을 원안으로 저장' → 간판 가로 6, 세로 80, 돌출 20으로 수정 | 원안(제한)과 수정안(부합) 그림이 나란히 표시, 바뀐 값 3개 |
| 4 | 구역을 '신택지개발지구'로 변경 | 다시 "제한 또는 위반 가능성"(판류형 금지, 글자 60cm 이하) |
| 5 | 간판 형태 '입체형', 세로 60으로 수정 | "확인된 기준에 부합" |
| 6 | 구역을 '정비시범구역'으로 변경 | "근거 미확인으로 판정 불가" |
| 7 | 구역을 '잘 모르겠음'으로 변경 | "추가 조건 확인 필요" |
| 8 | '인쇄·PDF로 저장' | 그림·결과·근거만 인쇄, "허가증이 아님" 문구 포함 |
| 9 | 기준 찾아보기에 '입체형' 입력 / '주차장' 입력 | 관련 기준 표시 / "찾지 못했습니다" |
| 10 | 주소를 `http://localhost:8765/?rules=sample#visual` 로 변경 | 같은 화면이 가상 지역 규칙으로 동작("가상 지역 예시 화면" 표시) |

## 4. 자동 점검 실행 (선택)

```
npm install playwright && npx playwright install chromium
python3 -m http.server 8765 &
node tests/site.test.js
```

마지막 줄에 `합계 63건 · 통과 63 · 실패 0`이 나오면 정상입니다.

## 5. 폴더 구성

| 경로 | 내용 |
|---|---|
| `index.html` | 화면 전체(첫 화면, 기존 메뉴 8개, AI 활용 안내) |
| `js/visual.js` | 그림으로 보는 설치기준 |
| `data/regulations.json` | 현행 기준 26건(출처·검증 상태·확인일) |
| `data/regulations.sample.json` | 가상 지역 규칙(구조 시연용, 실제 기준 아님) |
| `data/historical-visual-examples.json` | 2005년 참고자료 분석(판정에 쓰지 않음) |
| `data/biz.json` | 등록 옥외광고사업자 현황 |
| `tests/site.test.js` | 자동 점검 |
| `docs/` | 진단·분석·검증 기록, 제출자료 |

## 6. 알아 둘 점

- 경기도 조례 기준 11건은 법제처 해설로 확인했고, 화면에 "조례 원문 대조 전"이라고 표시됩니다.
- 정비시범구역 등 확인하지 못한 기준은 판정하지 않습니다.
- 그림 안내는 벽면 이용 간판과 돌출간판 두 종류입니다.
- 결과는 안내 참고용이며 허가·신고 여부는 담당 부서가 결정합니다.
