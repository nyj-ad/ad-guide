# 핵심 요약서

> 행사명·제출 형식·평가 항목·분량·마감일은 공고문을 받지 못해 **미확인**입니다. 공고문을 받으면 그 형식에 맞춰 다시 구성해야 합니다.

## 프로젝트명

AI 기반 옥외광고물 설치기준 시각화 및 시민 맞춤형 안내서비스 고도화

## 추진 배경

- 진건읍 옥외광고물 허가·신고는 2025년 50건, 2026년 1~8월 35건입니다(행정사무감사 자료).
- 2026년 35건 중 19건(54%)이 표시기간 연장·관리자 변경 같은 사후관리 민원이고, 표시허가 19건 중 3건이 취하·착오 접수였습니다.
- 간판 기준은 시행령, 경기도 조례, 남양주시 특정구역 고시로 나뉘어 있어 민원인이 직접 찾아 읽기 어렵습니다.

## 기존 문제점

- 기존 안내 페이지는 허가·신고 **대상 여부**만 알려 주고, 간판을 어디에 얼마나 크게 달 수 있는지는 "확인이 필요합니다"로 비어 있었습니다.
- 표시 기준 화면에 그림과 입력란이 없었습니다(그림 0개, 입력란 0개).
- 특정구역(진건지구 등)의 더 엄격한 기준이 반영되지 않았습니다.

## AI 활용 내용

| 단계 | AI(Claude)가 한 일 | 사람이 한 일 |
|---|---|---|
| 자료 분석 | 그림뿐인 PDF에서 사진 위 글자·선·색의 의미를 읽어 7건으로 구조화 | 자료 제공, 결과 검토 |
| 기준 정리 | 고시문 전문과 법제처 해설에서 규칙 26건을 조문·출처·확인일과 함께 데이터로 정리 | 고시문 원본 제공, 조례 원문 대조(예정) |
| 화면 설계·개발 | 건물 그림, 비교 프로그램, 자동 점검 51건 작성 | 디자인 방향 결정, 화면 확인 |
| 안전장치 | 미확인 기준은 판정하지 않도록 설계 | 최종 검토·배포 승인 |

서비스 화면에서 AI가 실시간으로 답을 만들지는 않습니다. 판정은 미리 확인해 둔 기준 데이터로만 합니다.

## 구현 결과

- **그림으로 보는 간판 설치기준**(새 메뉴): 간판 종류·구역·층·크기를 넣으면 건물 그림 위에 기준 범위(초록), 내 간판(파랑), 벗어난 부분(빨강 빗금)을 보여 줍니다.
- 판정 4가지: 부합 / 제한·위반 가능성 / 추가 확인 필요 / 근거 미확인으로 판정 불가
- 판정 항목마다 근거 조문 링크, 검증 상태, 확인일 표시
- 안내 결과 요약과 인쇄·PDF 저장
- 기준 찾아보기(검색형 안내, AI 챗봇 아님)

## 확인된 효과 (측정값)

| 항목 | 개선 전 | 개선 후 |
|---|---|---|
| 표시 기준 화면의 표시방법 수치 | 0건 | 규칙 26건(판정에 쓰는 것 24건) |
| 기준 설명 그림 | 0개 | 앞·옆 모습 그림, 입력값에 따라 바뀜 |
| 규칙별 출처·확인일 표시 | 없음 | 전 항목 표시 |
| 자동 점검 | 없음 | 51건 전부 통과 |

## 기대 효과 (측정 전)

- 착오 접수와 보완 요구 감소, 전화 문의 감소: 시범운영에서 측정할 예정이며 아직 수치가 없습니다.

## 확산 가능성

- 서버·예산 없이 GitHub Pages로 운영합니다.
- 기준이 데이터 파일로 분리되어 있어, 다른 시·군은 `data/regulations.json`만 자기 지역 조례·고시로 바꾸면 됩니다.
