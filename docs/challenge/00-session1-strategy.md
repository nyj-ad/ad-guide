# 세션1 출품 전략과 배점별 증거

- 출품 부문: 세션1 「AI 정부 실험실 챔피언십」(자유주제)
- 과제명: **간판 기준을 내 건물 그림으로 — AI 활용 시민 맞춤형 사전안내**
- 배점은 담당자가 전달한 안내서 요약을 따랐습니다. 안내서 원문은 이 작업에서 직접 확인하지 못했습니다.

## 한 문장

현장 공무원이 AI를 활용해 흩어진 간판 기준과 과거 시각자료를 구조화하고, 시민이 자기 조건을 넣어 기준과 차이를 그림으로 확인하는 사전안내 도구를 직접 개발했습니다.

## 차별성 세 가지 (모두 제출본에서 작동)

| 차별성 | 화면에서 확인하는 방법 | 자동 점검 |
|---|---|---|
| 읽는 기준을 조작하는 그림으로 | 간판 세로를 80 → 150으로 바꾸면 그림과 결과가 함께 바뀜 | "입력값 바꾸면 그림과 판정이 바뀜" |
| 같은 간판도 구역에 따라 다른 결과 | 판류형 6m×80cm 간판: 특정구역 밖은 부합, 신택지개발지구는 제한 | "신택지지구 + 판류형 → 제한" |
| 확인하지 못한 것은 판단 보류 | 구역을 정비시범구역으로 바꾸면 "근거 미확인으로 판정 불가" | "정비시범구역(미확인) → 판정 불가" |

## 이미지 기능의 범위

| 기능 | 이번 제출 |
|---|---|
| 입력값에 따라 바뀌는 건물·간판 그림 | 포함(주력) |
| 기준 범위·내 간판·벗어난 부분 표시 | 포함 |
| 원안과 수정안 비교 | 포함 |
| 자기 건물 사진에 영역 지정 | 미구현, 향후 계획 |
| AI의 벽면·창문 자동 탐지 | 미구현, 향후 계획 |
| 사진만으로 치수·적합 판정 | 범위에서 제외 |

설명 문구: "현재는 조건 입력에 따라 건물 도식과 기준을 비교합니다. 향후에는 자기 건물 사진에서 점포 영역을 지정하고, AI가 벽면·창문 후보를 제안하도록 확장합니다. 기준 대조는 검증된 규칙으로 유지합니다."
