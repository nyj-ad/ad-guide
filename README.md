# 옥외광고물 인허가 안내

남양주시 진건·퇴계원행정복지센터 도시건축과 건축팀이 운영하는 옥외광고물 허가·신고 민원 안내 웹페이지입니다.

- 바로가기: https://nyj-ad.github.io/ad-guide/
- 문의: 031-590-5859

## 주요 기능

| 메뉴 | 내용 |
|---|---|
| 허가·신고 대상 자가진단 | 광고물 종류·크기 질문으로 허가/신고/제외 판별 (시행령 제4조·제5조) |
| 광고물 종류별 표시 기준 | 종류별 허가·신고 기준 |
| 구비서류 체크리스트 | 허가·신고·변경·연장별 서류 (남양주시 민원편람 기준) |
| 처리 절차 및 처리 기간 | 허가 7일, 신고 3일, 심의 대상 20일 이내 |
| 수수료 안내 | 남양주시 조례 별표 3·4 수수료표와 자동 계산기 |
| 등록 광고업체 찾기 | 남양주시 「옥외광고업 현황」 검색 (매일 자동 갱신) |
| 자주 묻는 질문 | 14문항 |
| 문의처 | 담당 부서·전화번호·공식 자료 바로가기 |

## 수정 방법

`index.html` 파일 하나로 되어 있습니다. 파일 아래쪽 `<script>` 맨 위의 설정값만 고치면 내용이 바뀝니다.

- `CONTACT`: 기관명, 부서, 전화번호, 상담 시간
- `PERIOD`: 처리기간
- `LINKS`: 공식 자료 링크
- `FEE_RULES`: 허가·신고 수수료 (조례 별표 3)
- `SAFETY_RULES`: 안전점검 수수료 (조례 별표 4)

GitHub에서 `index.html`을 수정해 저장(Commit)하면 1~2분 뒤 페이지에 반영됩니다.

## 등록 광고업체 자동 갱신

- `.github/workflows/update-biz.yml`이 매일 오전 6시경(한국시간) 남양주시 누리집 사전행정정보 게시판을 확인합니다.
- 새 「○○년 옥외광고업 현황」 게시글이 있으면 첨부 엑셀을 내려받아 `data/biz.json`으로 변환하고 저장합니다. 게시글이 그대로면 아무것도 바꾸지 않습니다.
- 바로 확인하려면 저장소의 **Actions → 옥외광고업 현황 자동 갱신 → Run workflow**를 누르십시오.
- 변환 스크립트: `scripts/update_biz.py`
