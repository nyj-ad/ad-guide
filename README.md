# 간판 기준을 내 건물 그림으로 — AI 활용 시민 맞춤형 사전안내

남양주시 진건·퇴계원행정복지센터 도시건축과 건축팀이 직접 만든 옥외광고물 허가·신고 사전안내 웹페이지입니다.
간판 종류·구역·층·크기를 넣으면 건물 그림 위에 기준 범위와 내 간판의 차이를 보여 줍니다.

| 항목 | 내용 |
|---|---|
| 형태 | 웹페이지(설치·회원가입 없음, 휴대폰·PC 브라우저) |
| 접속 주소 | https://nyj-ad.github.io/ad-guide/ |
| 개발에 쓴 AI | Anthropic Claude (자료 구조화, 규칙 초안, 화면·코드·점검 작성) |
| 실행 중 쓰는 AI 모델 | 없음 (검증한 규칙 데이터로 대조) |
| 외부 연계·서버 | 없음 |
| 개인정보 | 수집 없음 |
| 문의 | 031-590-5859 |

## 바로 실행

Python 3만 있으면 됩니다.

```
python3 -m http.server 8765
```

브라우저에서 http://localhost:8765/ 를 열고 **내 간판 설치기준 알아보기**를 누릅니다.
index.html을 더블클릭해 열면 기준 자료를 읽지 못하니 위 방법으로 여십시오.

## 3분 확인 순서

| 번호 | 조작 | 기대 결과 |
|---|---|---|
| 1 | 벽면 이용 간판 → 특정구역 밖 → '범위를 벗어난 예' | "확인된 기준상 제한 또는 위반 가능성", 빨간 항목 3건 |
| 2 | '지금 값을 원안으로 저장' → 간판 가로 6, 세로 80, 돌출 20 | 원안(제한)·수정안(부합) 그림이 나란히 표시 |
| 3 | 구역을 '신택지개발지구'로 변경 | 같은 간판이 다시 "제한 또는 위반 가능성" |
| 4 | 구역을 '정비시범구역'으로 변경 | "근거 미확인으로 판정 불가" |
| 5 | 주소를 `/?rules=sample#visual` 로 변경 | 같은 화면이 가상 지역 규칙으로 동작 |

전체 시나리오와 자동 점검 방법: `docs/challenge/08-run-guide.md`

## 알아 둘 점

- 경기도 조례 기준 11건은 법제처 생활법령 해설로 확인했고, 화면에 "조례 원문 대조 전"으로 표시됩니다.
- 확인하지 못한 기준(정비시범구역 등)은 판정하지 않습니다.
- 그림 안내는 벽면 이용 간판과 돌출간판 두 종류입니다.
- 결과는 안내 참고용이며 허가·신고 여부는 담당 부서가 결정합니다.
- 2005년 참고자료의 사진·수치는 저장소에 없고 판정에도 쓰지 않습니다.

## 주요 기능

| 메뉴 | 내용 |
|---|---|
| 허가·신고 대상 자가진단 | 광고물 종류·크기 질문으로 허가/신고/제외 판별 (시행령 제4조·제5조) |
| 그림으로 보는 설치기준 | 건물 그림 위에서 내 간판과 기준 범위 비교, 원안·수정안 비교, 근거·확인일 표시 |
| 광고물 종류별 표시 기준 | 종류별 허가·신고 기준 |
| 구비서류 체크리스트 | 허가·신고·변경·연장별 서류 (남양주시 민원편람 기준) |
| 처리 절차 및 처리 기간 | 허가 7일, 신고 3일, 심의 대상 20일 이내 |
| 수수료 안내 | 남양주시 조례 별표 3·4 수수료표와 자동 계산기 |
| 등록 광고업체 찾기 | 남양주시 「옥외광고업 현황」 검색 (매일 자동 갱신) |
| 자주 묻는 질문 | 14문항 |
| 문의처 | 담당 부서·전화번호·공식 자료 바로가기 |

## 수정 방법

`index.html` 파일 하나로 되어 있습니다. 파일 아래쪽 `<script>` 맨 위의 설정값만 고치면 내용이 바뀝니다.

- `CONTACT`: 기관명, 부서, 전화번호, 상담 시간
- `PERIOD`: 처리기간
- `LINKS`: 공식 자료 링크
- `FEE_RULES`: 허가·신고 수수료 (조례 별표 3)
- `SAFETY_RULES`: 안전점검 수수료 (조례 별표 4)

GitHub에서 `index.html`을 수정해 저장(Commit)하면 1~2분 뒤 페이지에 반영됩니다.

## 등록 광고업체 자동 갱신

- `.github/workflows/update-biz.yml`이 매일 오전 6시경(한국시간) 남양주시 누리집 사전행정정보 게시판을 확인합니다.
- 새 「○○년 옥외광고업 현황」 게시글이 있으면 첨부 엑셀을 내려받아 `data/biz.json`으로 변환하고 저장합니다. 게시글이 그대로면 아무것도 바꾸지 않습니다.
- 바로 확인하려면 저장소의 **Actions → 옥외광고업 현황 자동 갱신 → Run workflow**를 누르십시오.
- 변환 스크립트: `scripts/update_biz.py`
